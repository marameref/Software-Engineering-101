# Week 0 — Developer Readiness & Environment Setup

## Practical Software Engineering Foundation Programme

**Duration:** 1 Week  
**Sessions:** 2–3 Instructor-Led Sessions  
**Session Duration:** 2 Hours  
**Level:** Beginner  
**Programme Stage:** Onboarding & Developer Readiness

---

## Week Overview

Week 0 prepares the student for the technical curriculum by establishing the basic tools, environment, digital organisation skills, and development habits required throughout the programme.

The objective is not to begin programming immediately, but to ensure that the student is comfortable navigating her computer, managing files and folders, using Visual Studio Code, understanding GitHub at a basic level, and interacting with the computer through the command line.

By the end of Week 0, the student's development environment should be fully configured and ready for Week 1.

---

## Learning Objectives

By the end of Week 0, the student should be able to:

- Understand the purpose of the software engineering programme.
- Understand how the 12-week programme will operate.
- Use basic professional digital communication tools.
- Navigate files and folders confidently.
- Understand common file extensions.
- Organise a software development workspace.
- Open and navigate Visual Studio Code.
- Understand the basic purpose of GitHub.
- Understand what a terminal/command line is.
- Execute basic terminal commands.
- Navigate directories using the terminal.
- Understand basic file paths.
- Develop good habits for organising technical work.
- Perform simple technical tasks with increasing independence.

# Session 3 — Command Line & Developer Readiness

## 1. Introduction to the Terminal

Topics include:

- What a terminal is

- Graphical User Interface (GUI)
- CLI vs GUI
- Why developers use terminals
- Opening a terminal
- VS Code integrated terminal
- Current working directory

---

## 2. Basic Terminal Commands

The student will practise commands for navigating and managing directories.

### Display Current Location

```bash
pwd
```

### Display Directory Contents

```bash
ls
```

### Navigate Into a Directory

```bash
cd folder-name
```

### Return to Parent Directory

```bash
cd ..
```

### Create a Directory

```bash
mkdir folder-name
```

### Clear the Terminal

```bash
clear
```

Additional commands may be introduced depending on the operating system and shell being used.

> The objective is not to memorise commands, but to understand what they do and become comfortable using the command line.

---

# Developer Habits

Week 0 introduces several habits that will be reinforced throughout the programme.

The student is encouraged to:

- Read instructions carefully.
- Attempt problems before requesting solutions.
- Ask clear technical questions.
- Read error messages.
- Research unfamiliar concepts.
- Keep project files organised.
- Use meaningful file and folder names.
- Save work properly.
- Take technical notes.
- Explain concepts in her own words.
- Understand commands rather than simply copying them.

> **Core Principle:** Understand what you are doing rather than simply copying instructions.
