# 🌟 Programme Overview

Welcome to the **12-Week Software Engineering Foundation & Practical Mentorship Programme**, a structured, hands-on learning experience developed by **Opsfuxion Technologies Limited**.

This programme is designed for aspiring software engineers, particularly students preparing to begin undergraduate studies in Software Engineering, Computer Science, or related technology disciplines.

Our approach combines **fundamental computer science concepts, practical programming, modern development tools, problem-solving, and professional software engineering practices**.

Rather than simply learning to write code, students will develop the ability to understand problems, design solutions, implement applications, debug errors, and communicate their technical decisions.

> 💡 **Our Learning Philosophy**
>
> We don't just teach students how to write code. We help them understand how software works, why engineering decisions matter, and how to approach problems with confidence and curiosity.

---

# 🎯 Programme Objectives

By the end of the programme, students should be able to:

- ✅ Understand fundamental software engineering concepts and practices.
- ✅ Explain how websites and software applications work.
- ✅ Build structured webpages using HTML and CSS.
- ✅ Create basic responsive website layouts.
- ✅ Use Git and GitHub for version control.
- ✅ Write beginner-level Python programs.
- ✅ Apply programming logic and algorithmic thinking.
- ✅ Work with Python data structures.
- ✅ Organise programs using functions and modules.
- ✅ Understand introductory Object-Oriented Programming (OOP).
- ✅ Implement basic data structures and algorithms.
- ✅ Understand relational databases and SQL.
- ✅ Apply introductory software testing and debugging techniques.
- ✅ Write technical documentation.
- ✅ Complete and present a practical software project.

# 🧑‍🏫 Learning Methodology

The programme adopts a practical, learner-centred teaching approach.

## The Learn → Build → Review Model

| Stage | Description |
|:---|:---|
| 📘 Learn | Understand new concepts through guided explanations and demonstrations. |
| 🛠️ Build | Apply knowledge through practical coding exercises and assignments. |
| 🔍 Review | Evaluate completed work, discuss challenges, and improve solutions. |

### Weekly Learning Structure

**Session 1 — Concept Introduction**

- Introduce core topics.
- Explain foundational concepts.
- Demonstrate practical examples.
- Assign introductory exercises.

**Session 2 — Guided Practical Development**

- Review previous assignments.
- Expand technical understanding.
- Build practical solutions.
- Introduce independent challenges.

**Session 3 — Project Development & Review**

- Review completed exercises.
- Implement the weekly project.
- Debug and improve solutions.
- Assess understanding.
- Prepare for the next module.
